# Tellama v1.3.7 — Runtime 2.0

기기 안에서 실행 성능을 측정하고, 지원 기기의 GPU를 안전하게 활용하며, 다국어 의미 기억을 오프라인으로 준비하는 업데이트입니다.

## 주요 변경

- **실행 성능 최적화:** 속도·균형·품질·배터리 목표와 로컬 CPU 튜닝을 제공합니다. 정밀 최적화는 현재 모델을 측정하며 채팅/API 요청을 우선 처리합니다.
- **지원 Adreno GPU 가속:** 정밀 최적화에서 CPU와 비교해 출력·속도·첫 응답·메모리·발열 조건을 통과할 때만 GPU를 채택합니다. 미지원 기기나 기준 미달은 CPU를 유지합니다.
- **GPU 장애 복구:** 별도 작업 프로세스로 드라이버 오류를 격리하고, 오류 안내 후 CPU에서 다시 질문할 수 있게 합니다. 복구 실패를 준비 완료로 표시하지 않습니다.
- **오프라인 의미 기억:** 다국어 의미 검색 모델을 기본 포함합니다. 첫 실행 때 검증 후 기기에서 준비하며 기존 기억을 유지합니다. 대화용 GGUF 모델은 별도로 선택합니다.
- **런타임 안정성:** 모델/세션 소유권, 채팅/API별 컨텍스트, 메모리 재검사와 발열 대응을 개선했습니다.
- **업데이트 안내:** 앱 화면 복귀 때도 확인합니다. 정상 확인은 6시간 간격, 실패 시 5분 후 다음 복귀에서 재확인하며 같은 버전 재안내는 24시간 간격입니다.
- **업데이트 설치 재개:** 앱을 다시 열었을 때 이미 다운로드·검증한 APK의 설치 준비 상태를 먼저 복원해 불필요한 재다운로드를 방지합니다.

## 성능 참고

Galaxy Z Fold6의 TinyLlama Q4_0, 512 컨텍스트, 32토큰 시험에서 GPU 생성 속도 중앙값은 47.97 tok/s였습니다. 전후 CPU 측정 중 더 빠른 30.83 tok/s 대비 약 55.6% 개선됐습니다. 첫 토큰은 406ms에서 244ms로 줄었습니다. 이는 해당 모델·조건의 짧은 시험 결과이며 다른 모델·기기·장시간 사용의 보장치는 아닙니다. GPU가 항상 더 빠른 것은 아니므로 실측 기준을 적용합니다.

## 기존 사용자 업데이트

앱 실행 시 안내를 확인하거나 **설정 → 앱 업데이트 → 업데이트 센터**를 열어주세요. 다운로드와 무결성·패키지·버전·서명 확인 후 Android 설치를 승인하면 됩니다. 자동 확인 간격 때문에 안내가 즉시 뜨지 않을 수 있습니다. 앱을 지우지 않고 업데이트하면 기존 모델·대화·기억을 유지합니다.

앱을 열지 않은 사용자에게 보내는 푸시 알림이나 무인 설치는 아닙니다. v1.2.0의 Android 10 사용자는 릴리즈 APK를 한 번 직접 설치해야 합니다.
