# Tellama v1.3.8 — Resumable updates / 업데이트 이어받기

## 주요 변경

- 업데이트 전송이 중단돼도 받은 파일을 보존하고 이어받습니다.
- HTTP Range 응답과 전체 SHA-256·패키지·버전·서명 검증을 함께 적용합니다.
- 다운로드 진행 알림·취소 기능을 제공하고, 진행률 저장에 따른 불필요한 부하를 줄였습니다.
- 대기·재개 상태를 정확하게 표시하고 저장공간 부족을 `UPDATE_009`로 별도 안내합니다.
- Runtime 2.0의 CPU 최적화·지원 Adreno GPU 가속·오프라인 의미 기억을 그대로 포함합니다.

## 기존 사용자 중요 안내

**1.3.7 이하 앱에서 아주 느린 업데이트가 처음부터 반복될 수 있습니다.** Android 16에서
기존 작업이 30분 뒤 종료되는 현상을 실제로 확인했습니다. 이 경우 이 릴리스의 APK를
브라우저로 받아 **앱을 삭제하지 않고 기존 앱 위에 설치**하세요. 모델·대화·기억을 유지합니다.
새 이어받기 기능은 1.3.8 설치 이후 적용됩니다. 이미 설치된 구버전 코드를 원격 수정하지는 못합니다.

앱 실행/복귀 시 새 버전 안내 또는 설정 → 앱 업데이트에서 확인할 수 있습니다.
즉시 푸시나 무인 설치가 아니며 Android 설치 승인이 필요합니다.

## English summary

Update downloads now retain partial files and resume with validated HTTP ranges. Full SHA-256,
package, version and signing checks remain mandatory. This release also adds progress notifications,
clearer waiting states and a dedicated low-storage error.

**If updating from 1.3.7 or earlier restarts from zero on a slow connection, download this APK in your
browser and install it over Tellama without uninstalling.** The resume fix only takes effect after 1.3.8
is installed. Automatic in-app notices are not push notifications or unattended installation.
