# Tellama v1.3.9 — TM models and reliable serving / 검증 모델과 서빙 경험

## 주요 변경

- **내 모델 / 모델 찾아보기**를 분리해 설치·다운로드·서빙 상태를 명확하게 표시합니다.
- 검증 미통과 추천은 새 다운로드 목록에서 제외하며 기존 모델·대화·기억은 보존합니다.
- **TM Qwen3 4B Q4_K_M**을 Tellama에서 직접 양자화해 기존 모델 저장소로 제공합니다.
  Qwen 원저작자 표시와 Apache-2.0 라이선스를 유지합니다. Q8 임베딩/출력 텐서를 포함합니다.
- DEEP 모드 전환에 명시적으로 동의하고 모델과 모드를 함께 적용합니다. 실패 시 이전 설정을 복구합니다.
- 빈 응답을 끝없이 기다리는 현상과 실패한 대화 항목의 후속 프롬프트 혼입을 수정했습니다.
- 발열 중단은 별도 알림으로 안내하고 일반 저장 오류를 암호키 손실로 잘못 안내하지 않습니다.
- 모델 교체 후 새 메모리 검사·안전한 로딩 복구와 15개 언어 오류 안내를 보완했습니다.
- 홈페이지 PC·모바일 레이아웃과 모델 설명, 실제 Android 화면을 업데이트했습니다.

## 검증 범위와 모델 제한

Fold6 CPU/DEEP/4,096문맥/F16 캐시에서 정확한 2.59 GB 파일이 54/55개 및 모든 필수
검사를 통과했습니다. 한글 JSON 도시명을 영어로 번역한 비필수 검사 1건은 남아 있습니다.
최저 디코드 속도는 3.76 tokens/s였고 일부 응답은 2분 이상 걸렸습니다. 이 파일의 FAST·GPU·
다른 모든 기기 성능을 보장하지 않습니다. 메모리·발열 안전장치를 유지하세요.

실기기 모델 자동 교체·원래 모델 복귀, 실제 Hugging Face 전체 다운로드·중단·재개·SHA 검증,
서명된 정식 APK의 메뉴·DEEP 동의·서빙·연속 대화, 705개 단위 테스트와 양 채널 린트를 확인했습니다.
모델 품질/교체는 Fold6, 전체 다운로드 및 정식 APK 블랙박스 E2E는 Android16 에뮬레이터에서 실행했습니다.

[모델·라이선스·검증 보고서](https://huggingface.co/LaraAI-Labs/tellama)

## 업데이트

앱 실행·복귀 시 정상 확인 주기에 따라 새 버전 안내를 받거나 **설정 → 앱 업데이트**에서
직접 확인하세요. 즉시 푸시·무인 설치가 아니며 Android 설치 승인이 필요합니다.
**기존 앱을 삭제하지 말고 위에 설치해야 모델·대화·기억이 유지됩니다.**

1.3.7 이하에서 느린 다운로드가 처음부터 반복되면 공식 APK를 브라우저로 받아 덮어 설치하세요.
이어받기 수정은 1.3.8부터 적용되며 이미 설치된 구버전 코드를 원격으로 바꾸지는 못합니다.
모델 다운로드에는 Hugging Face 연결이 필요합니다. 해당 호스트가 차단된 네트워크에서는 받을 수 없습니다.

## English summary

Installed and downloadable models now have separate views. The exact Tellama-quantized Qwen3 4B
artifact is approved for Fold6 CPU/DEEP/4096/F16 only:54/55 checks, all critical checks passed.
One Korean JSON city translation remains; some replies take over two minutes. Explicit mode consent,
empty-response recovery, thermal notices and consistent serving errors improve the workflow.
Existing installed models remain available. Install over the current app without uninstalling.
Automatic in-app checks follow the normal schedule; Android still requires installation approval.
