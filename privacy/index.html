Privacy Policy

Tellama is built around local AI on Android. Prompts, responses, chat history, Memory items, API keys, and diagnostics are designed to stay on the user's device unless the user explicitly chooses otherwise.

Effective October 2, 2026 Android package: com.tellama.app No Tellama account required

Effective date: October 2, 2026

Tellama is a local AI app for Android. It lets you import or download supported local model files, chat with models on your device, save user-approved Memory items, and optionally run a local API server.

This policy applies to the Tellama Android app published as com.tellama.app.

Distribution Editions

The Google Play edition does not include the local API server or GitHub APK self-updates. Those features described below apply only to the direct-download edition. The Play edition accepts only HTTPS external API endpoints. Prompts, conversation context, relevant Memory and attached text may be sent to an external provider when you choose that provider.

Data We Store on Your Device

Tellama stores the following data locally on your Android device:

  • Chat sessions, prompts, and responses.
  • User-approved Memory items.
  • Installed or imported model metadata and checksums.
  • Local API server client keys are stored as SHA-256 hashes; the raw key is shown only once. Keys you enter for external providers are stored in the encrypted local database (not hashed) so Tellama can authenticate to the provider you chose.
  • Failure records and diagnostics used for Safe Mode and support reports.
  • User settings such as language, theme, and download preferences.
  • Optional local profile details such as display name, contact email, update opt-in preference, and profile photo URI.

Tellama uses an encrypted local database. Android backup is disabled for app data.

Optional Profile and Product Updates

Tellama does not require an account for local use. You may optionally add a local display name, contact email, and profile photo in Settings. These profile details stay on your device unless you choose to share them.

The optional profile (display name, contact email, and photo) and the "product updates" preference are stored only in Tellama's private on-device storage. Tellama does not transmit your profile or email address anywhere, and there is no Tellama account. The "product updates" toggle is a local preference only.

Voice Input

Tellama does not request the microphone permission. Voice input launches the Android system speech recognizer, which captures and processes the audio on its own and returns only recognized text. Tellama never records or stores raw audio. Recognized text is stored only if you send it as a chat message.

Network Use

Tellama does not require an account for local use.

Tellama uses network access for:

  • User-initiated model downloads from the selected model provider over HTTPS.
  • Direct-download edition only: release checks and user-initiated APK downloads from GitHub.
  • External OpenAI-compatible API models configured and selected by the user.
  • Web research against user-selected public HTTPS pages.
  • Android system speech recognition when the installed speech service uses a network.
  • Direct-download edition only: optional local API serving.

The API server is off by default. Local Only mode binds to 127.0.0.1. Both Local Only and LAN modes require API key (Bearer) authentication so other apps on the same device cannot call Tellama without a key. LAN mode additionally requires explicit user action. Local LAN API traffic is not TLS-encrypted, so enable LAN mode only on networks you trust.

Tellama does not send prompts, responses, chat history, Memory items, API keys, or voice transcripts to Tellama-controlled cloud servers.

Tellama does not automatically upload your optional local profile or profile photo.

External API Models

If you add or select an OpenAI-compatible external API model, Tellama sends the prompt and context required for that request to the endpoint you configured. The external provider's privacy, retention, security, content, and billing terms apply. Tellama displays an in-app disclosure before external-model use. Remove the external model and its credentials to stop future use.

Web Research

Web research makes direct HTTPS requests to the public URL you provide. Tellama blocks unsupported schemes, local or private network targets, unsafe redirects, authentication paths, and oversized or unsupported responses.

With a local model, fetched page text is processed on the device. With an external API model, the page text needed for summarization or comparison is sent to the configured provider after an in-app warning.

Model Downloads and App Updates

Model downloads connect to the selected third-party model host. The host receives ordinary request metadata such as your IP address and user-agent information. Tellama verifies supported model files before use.

The direct-download edition may check the public GitHub release feed for a newer version. When you start an update, the APK is downloaded from GitHub and Tellama verifies its SHA-256 digest, package name, higher version, and signing certificate before opening Android's installer. GitHub's privacy terms apply to these requests.

Support Reports

Tellama generates and displays diagnostics locally in Settings. It redacts bearer tokens, API keys, and local filesystem paths before presenting support data. The current app does not upload diagnostics or include a support-report sharing action.

Data Sharing

Tellama does not sell user data and does not share user data with advertising networks.

Data may leave the app only when:

  • You use an external API model, which sends the required prompt and context to the provider you configured.
  • You run web research against a public HTTPS page. With an external API model, the fetched page text required for the request is also sent to that provider after an in-app warning.
  • You download a model from a third-party model host or, in the direct-download edition, an app update from GitHub.
  • You explicitly export a conversation and choose an Android share target. The exported text contains the visible messages, roles and timestamps; the selected app or service controls further handling.
  • You use Android system speech recognition, which is controlled by your installed speech service and may process audio or text remotely.
  • In the direct-download edition, you enable local API serving and connect your own local clients to the app.

Retention

Local data remains on your device until you delete it, clear Tellama storage, or uninstall the app. Tellama does not control the retention practices of external API providers, GitHub, model hosts, website operators, email providers, or Android speech services; review the applicable provider's policy before using that feature.

Data Deletion

You can delete local Tellama data by:

  • Clearing or editing your optional profile in Tellama Settings.
  • Opening Tellama Settings and resetting Memory.
  • Clearing Tellama storage in Android system settings.
  • Uninstalling Tellama.

Because Tellama does not require a Tellama account or run a Tellama cloud account service, there is no server-side account data to delete.

Children

Tellama is intended for developers, local AI users, and general productivity use. It is not directed to children.
