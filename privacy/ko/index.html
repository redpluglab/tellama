개인정보 처리방침

Tellama는 안드로이드에서 로컬 AI를 실행하도록 설계되었습니다. 사용자가 연결 기능을 직접 선택하지 않는 한 대화, 응답, 대화 기록, 메모리, API 키와 진단 정보는 기기 안에 보관됩니다.

시행일 2026년 10월 5일패키지 com.tellama.app계정 불필요
핵심 요약: 일반적인 TM 대화 추론은 기기에서 처리됩니다. AI 응답을 신고할 때는 사용자가 확인·동의한 신고 내용만 서버로 전송합니다. 웹 리서치, 모델 다운로드, Android 음성 인식, 대화 내보내기와 직접 배포판의 앱 업데이트·로컬 API 서빙은 사용자의 선택에 따라 네트워크 전송 또는 공유가 발생할 수 있으며 해당 제3자의 약관이 적용됩니다.

배포판별 기능

Google Play 배포판에는 로컬 API 서버와 GitHub APK 자체 업데이트 기능이 없습니다. 아래에서 설명하는 해당 기능은 직접 다운로드한 배포판에만 적용됩니다. 이번 출시에서는 외부 AI API 연결과 임의 모델 가져오기를 제공하지 않습니다. 앱 카탈로그에서 제공하는 검증된 TM 모델로 기기에서 대화합니다.

기기에 저장하는 정보

Tellama는 대화 세션, 프롬프트, 응답, 사용자가 승인한 메모리, 설치·가져오기한 모델의 메타데이터와 체크섬, 로컬 API 클라이언트·실패 기록, 진단 정보, 설정과 선택적 프로필 정보를 Android 기기에 저장합니다.

로컬 API 서버용 클라이언트 키는 SHA-256 해시로 저장하며 원문은 생성 시 한 번만 표시합니다. 이전 버전에서 저장된 외부 제공업체 설정은 암호화된 로컬 데이터베이스에 남지만, 이번 출시에서는 해당 설정으로 요청을 전송할 수 없습니다. 로컬 데이터베이스는 암호화하며 Android 앱 데이터 백업은 비활성화합니다.

선택적 프로필과 제품 소식

로컬 사용에는 계정이 필요하지 않습니다. 설정에서 이름, 이메일, 프로필 사진을 선택적으로 추가할 수 있으며 사용자가 공유하지 않는 한 기기 안에만 보관됩니다.

선택적 프로필(이름·이메일·사진)과 "제품 소식" 설정은 Tellama의 기기 내 비공개 저장소에만 보관됩니다. Tellama는 프로필이나 이메일 주소를 자동 전송하지 않으며 계정도 없습니다. 사용자가 신고 본문에 직접 입력한 개인정보는 신고를 전송할 때 함께 전달됩니다. "제품 소식" 토글은 로컬 설정일 뿐입니다.

음성 입력

Tellama는 마이크 권한을 요청하지 않습니다. 음성 입력은 Android 시스템 음성 인식기를 실행하며, 마이크는 시스템 음성 서비스가 직접 소유·처리하고 Tellama에는 인식된 문장만 전달됩니다. 원본 음성은 저장하지 않으며, 인식된 문장은 사용자가 채팅으로 전송했을 때만 대화에 저장됩니다.

네트워크 사용

사용자가 시작한 HTTPS TM 모델 다운로드, 확인·동의한 AI 응답 신고, 사용자가 지정한 공개 HTTPS 페이지에 대한 웹 리서치와 Android 음성 서비스가 네트워크를 사용할 수 있습니다. GitHub 릴리즈 확인·APK 업데이트 및 선택적 로컬 API 서빙은 직접 배포판에서만 제공됩니다.

직접 배포판의 API 서버는 기본적으로 꺼져 있습니다. 로컬 전용 모드는 127.0.0.1에 바인딩합니다. 로컬 전용·LAN 모드 모두 API 키(Bearer) 인증이 필요하므로 같은 기기의 다른 앱도 키 없이 호출할 수 없습니다. LAN 모드는 사용자가 직접 켜야 하며 트래픽은 TLS로 암호화되지 않으므로 신뢰하는 네트워크에서만 사용해야 합니다.

외부 API 모델

이번 출시에서는 외부 AI API 연결을 사용할 수 없습니다. 저장된 외부 모델 선택이나 인증 정보로 네트워크 요청을 시작할 수 없습니다. 업데이트는 기존 로컬 대화, 모델 파일과 설정을 지우지 않습니다.

웹 리서치

사용자가 입력한 공개 HTTPS URL에 직접 요청합니다. 로컬·사설 네트워크 대상, 안전하지 않은 리디렉션, 인증 경로, 지원하지 않는 형식과 과도하게 큰 응답을 차단합니다. 가져온 페이지 텍스트는 검증된 TM 모델로 기기에서 처리합니다.

모델 다운로드와 앱 업데이트

모델 다운로드는 사용자가 선택한 제3자 모델 제공처에 연결하며, 제공처는 IP 주소와 사용자 에이전트 같은 일반적인 요청 정보를 받을 수 있습니다. Tellama는 지원하는 모델 파일을 사용하기 전에 검증합니다.

직접 배포판은 공개 GitHub 릴리즈 피드에서 새 버전을 확인할 수 있습니다. 업데이트를 시작하면 GitHub에서 APK를 받고 SHA-256, 패키지명, 상위 버전과 서명 인증서를 검증한 뒤 Android 설치 화면을 엽니다. 이 요청에는 GitHub의 개인정보 처리 조건이 적용됩니다.

선택적 AI 응답 신고

완료된 AI 응답을 채팅 화면에서 신고할 수 있습니다. 신고창에서 선택한 응답 본문을 수정하고 사유와 선택적 설명을 입력합니다. 동의는 기본 해제되어 있으며 동의 전에는 전송할 수 없습니다. 내용을 수정하면 동의가 다시 해제되고, 창을 닫으면 전송하지 않은 초안은 폐기됩니다.

전송 항목은 확인한 본문, 선택적 설명, 사유, 무작위 접수번호, 앱 버전, 언어 및 스키마 버전입니다. 다른 메시지·숨겨진 추론·프로필·메모리·인증키·파일·진단 정보는 자동 첨부하지 않습니다. 신고에 개인정보를 직접 포함할 수 있으므로 보내고 싶지 않은 정보는 전송 전에 지워 주세요. GitHub 계정은 필요하지 않습니다.

Cloudflare가 HTTPS로 신고를 받고 Tellama 개발자가 사용하는 비공개 GitHub 저장소로 전달합니다. 신고된 AI 콘텐츠를 검토하고 안전성·앱 문제를 해결하기 위한 처리이며, 현재 구현은 신고를 광고·분석·모델 학습 파이프라인으로 보내지 않습니다. 해당 비공개 저장소에 접근 권한이 있는 운영자는 신고를 읽을 수 있습니다.

본문과 설명은 GitHub Issues에 저장합니다. Cloudflare D1에는 접수번호, 전송 항목의 해시, 처리 상태, 이슈 번호 및 시각만 저장하여 중복 접수 방지와 중단된 요청 복구에 사용합니다. D1에는 신고 본문이나 IP 주소를 저장하지 않습니다. 해시·접수번호가 익명성을 보장하는 것은 아닙니다.

Cloudflare는 IP 주소 등 접속 정보를 받고 요청 남용 제한에 IP를 사용합니다. Worker 애플리케이션 로그·추적은 꺼 두었으나, 제공자는 별도로 네트워크·보안·운영 정보를 처리할 수 있습니다. Cloudflare 개인정보처리방침과 GitHub 개인정보처리방침을 확인해 주세요. 제공자는 거주 국가 밖에서 정보를 처리할 수 있으며 국내 전용 보관 서비스로 안내하지 않습니다.

연결은 HTTPS로 보호하지만 개발자와 권한 있는 서비스 제공자가 신고를 읽을 수 있으므로 이들에 대한 종단간 암호화는 아닙니다. 이슈를 닫는 것만으로는 본문이 삭제되지 않습니다.

지원 보고서

Tellama는 설정에서 진단 정보를 기기 안에서 생성하고 표시합니다. 표시 전에 Bearer 토큰, API 키와 로컬 파일 경로를 가립니다. 현재 앱은 진단 정보를 업로드하거나 지원 보고서를 공유하는 기능을 제공하지 않습니다.

정보 공유

Tellama는 사용자 정보를 판매하거나 광고 네트워크와 공유하지 않습니다.

명시적으로 동의한 AI 응답 신고, 웹 리서치, 모델 다운로드, 대화 내보내기 또는 원격 처리를 사용하는 Android 음성 서비스를 통해 정보가 앱 밖으로 나갈 수 있습니다. 직접 배포판에서는 GitHub 앱 업데이트와 사용자가 켠 로컬 API 클라이언트 연결도 포함됩니다. Tellama는 대화 기록, 메모리, API 키, 음성 인식 문장이나 프로필 사진을 자동 업로드하지 않습니다. 사용자가 직접 신고에 포함하고 확인·동의한 내용은 신고 서버에 전달됩니다.

대화를 내보내고 Android 공유 대상을 선택하면 화면에 표시되는 메시지, 역할과 시간이 텍스트로 전달됩니다. 이후 처리는 사용자가 선택한 앱 또는 서비스가 담당합니다.

보유 및 삭제

로컬 정보는 사용자가 삭제하거나 Tellama 저장공간을 지우거나 앱을 제거할 때까지 기기에 남습니다. 프로필 편집, 설정의 메모리 초기화, Android 앱 저장공간 삭제 또는 앱 제거로 로컬 정보를 삭제할 수 있습니다.

신고 본문은 접수일부터 최대 90일, 본문 없는 접수 메타데이터는 최대 180일 보관합니다. 검토 또는 삭제 요청에 따라 더 일찍 삭제할 수 있으며, 기한 전에 주기적으로 만료 삭제를 시작합니다. 신고는 별도 서버 데이터이므로 앱 삭제나 로컬 대화 삭제만으로 없어지지 않습니다.

신고 삭제는 support@redplug.co.kr에 전송 후 표시된 접수번호를 알려 요청할 수 있습니다. 신고 본문이나 인증 정보를 다시 보내지 마세요. 접수번호로 해당 신고를 확인하여 GitHub 이슈를 삭제하고 접수 메타데이터만 위 보관 기간 내에서 유지합니다. 이메일 요청은 이메일 제공자가 별도로 처리합니다.

위 기간은 Tellama가 관리하는 활성 신고 기록에 적용됩니다. 현재 Cloudflare D1 무료 요금제는 최대 7일의 복구 이력을 지원하므로 삭제된 접수 메타데이터가 해당 기간 복구 이력에 남을 수 있습니다. 이는 GitHub 본문에 대한 설명이 아닙니다. D1 복구 이력 안내를 확인해 주세요. GitHub·Cloudflare는 자체 운영 또는 법적 목적의 정보를 각 정책에 따라 보관할 수 있으며 GitHub 백업의 확정된 삭제 기한은 확인되지 않았습니다. 모델 제공처·웹사이트·이메일·Android 음성 서비스에는 각 제공자의 정책이 적용됩니다.

Tellama 계정은 필요하지 않습니다. 계정 유무와 별개로 직접 제출한 신고는 위 절차로 서버에서 삭제를 요청할 수 있습니다.
